新任务将适用门置为 `pending`。通过后填写 `pass`，失败时填写 `fail`。G6 适用且本次既无需部署也无需修改数据时，可以填写 `n/a`，并在缺项列给出理由。

`界面` 表示本次变更是否涉及界面。`后端` 表示本次变更是否涉及后端代码、接口或数据。轻量变更分别写 `有` 或 `无`，至少一项填 `有`。热修按本次范围填写。

`数据库` 描述验证环境是否使用数据库。确认无数据库时写 `无`。有数据库或待判定时，G6 需要备份和恢复证据。

每次热修在 H0 判断 `热修安全影响`。办理 G4 前明确填 `有` 或 `无`。

`规模` 表示项目配置。选择 `标准` 或 `小`。轻量变更和热修使用本次唯一的变更编号。适用工件头、状态板的版本列和热修批准记录都使用该编号。

`DONE` 只表示本模式流程结束。验证发布按批准范围执行。
